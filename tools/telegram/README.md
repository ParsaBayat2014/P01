# ورود محلی تلگرام در ویندوز

این ابزار برای ورود به حساب خودتان و اجرای دستورهای صریح محلی است. حساب یا ربات واسطه‌ای برای تولید استرینگ لازم ندارد.

۱. با حساب خودتان به https://my.telegram.org بروید و بخش API development tools را باز کنید. برای برنامه خودتان api_id و api_hash بگیرید. شناسه نمونه عمومی تلگرام محدود به آزمایش است.
۲. فایل setup-telegram.cmd در ریشه مخزن را روی کامپیوتر خودتان اجرا کنید. Python باید نصب باشد. این فایل یک محیط مجازی می‌سازد و Telethon را نصب می‌کند.
۳. شناسه برنامه، هش، شماره، کد ورود و در صورت فعال‌بودن رمز دومرحله‌ای را فقط در پنجره محلی وارد کنید. اطلاعات ورود در مخزن یا چت وارد نمی‌شوند.

نشست از نوع StringSession در حافظه ساخته و سپس با Windows DPAPI برای کاربر فعلی ویندوز رمز می‌شود. فایل آن در پوشه .money-private قرار می‌گیرد؛ استرینگ در خروجی چاپ نمی‌شود. آن پوشه و محیط مجازی از گیت کنار گذاشته شده‌اند. فایل نشست را به GitHub یا چت نفرستید.

بعد از ورود، دستور status فقط هویت حساب را تأیید می‌کند:

    .venv\Scripts\python.exe tools\telegram\telegram_local.py status

فهرست محدود گفتگوها:

    .venv\Scripts\python.exe tools\telegram\telegram_local.py dialogs --limit 20

دستور messages به شناسه عددی دقیق یک گفتگوی موجود نیاز دارد. دستور send علاوه بر شناسه مقصد به شناسه تأیید حساب و یک فایل متنی UTF-8 نیاز دارد. این ابزار ارسال انبوه، ارسال به نام حدس‌زده‌شده، حذف پیام، برداشت پول یا تأیید واریز انجام نمی‌دهد.

## محدودیت اجرایی

این کد به‌تنهایی ChatGPT را به حسابتان وصل نمی‌کند و مدیر دائمی یا پاسخ‌گوی هوشمند پس‌زمینه نیست. اجرای مستمر، اتصال برنامه به ابزارهای قابل دسترس دستیار و آزمون واقعی حساب هنوز نیاز به راه‌اندازی جداگانه دارد. داشتن فایل نشست به معنای انجام‌شدن این اتصال نیست.

ورود واقعی با حساب کاربر آزمایش نشده است. راهنمای CLI بررسی شده است. آزمون DPAPI در محیط اجرای ساخت با WinError 2 ناموفق بود؛ بنابراین کارکرد رمزگذاری در این محیط تأیید نشده است. ابزار پیش از درخواست هر اطلاعات ورود، رمزگذاری را بررسی می‌کند و در صورت شکست، ورود را متوقف می‌کند. برای اجرا به پروفایل معمول و فعال ویندوز خودتان نیاز دارید. برای لغو یک نشست، از Settings > Devices در تلگرام رسمی استفاده کنید.
