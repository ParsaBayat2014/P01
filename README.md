# نمونه‌کارهای فارسی پارسا بیات

دو نمونه فرضی و یک صفحه معرفی خدمات برای شروع مذاکره با کسب‌وکارهای ایرانی.

- index.html: صفحه معرفی خدمات و نمونه‌کارها.
- samples/ava/index.html: صفحه آموزشگاه زبان فرضی آوا.
- samples/cafe/index.html: منوی کافه فرضی برگ با دسته‌بندی و جست‌وجو.

همه نام‌ها، نظرات، محصولات و اطلاعات داخل دو نمونه فرضی‌اند. این‌ها سفارش مشتری واقعی یا شواهد فروش و درآمد نیستند. منوی برگ دریافت سفارش یا پرداخت ندارد.

## اجرا

فایل index.html را در مرورگر باز کنید، یا داخل پوشه پروژه دستور زیر را اجرا کنید:

    python -m http.server 8000

سپس http://localhost:8000 را باز کنید. فایل‌ها به سرویس بیرونی، فونت خارجی یا نصب بسته وابسته نیستند.

## پیشنهاد اولیه

یک صفحه معرفی فارسی، حداکثر شش بخش، سازگار با موبایل، دکمه تماس و یک نوبت اصلاح: **۳٬۰۰۰٬۰۰۰ تومان = ۳۰٬۰۰۰٬۰۰۰ ریال**. دامنه و میزبانی جداست. امکانات ثبت‌نام، پنل مدیریت و پرداخت آنلاین در این مبلغ نیستند.

مبنای مقایسه قیمت اعلامی در ۲۳ اکتبر ۲۰۲۶:

این اعداد متوسط بازار نیستند و محدوده سرویس‌ها متفاوت است.

## وضعیت بررسی

ساختار فایل‌ها و ارجاع‌های محلی بررسی شده‌اند و JavaScript با node --check کنترل شده است. آزمون تعاملی و بازبینی تصویری مرورگر در محیط ساخت در دسترس نبوده است. وجود کد در این مخزن به معنای انتشار روی GitHub Pages نیست.

هیچ استرینگ نشست، توکن، شماره کارت، فهرست مشتری یا مکاتبه خصوصی در این مخزن قرار ندارد.
